# Study 2 比較対象の設計案

記録日: 2026-10-28

状態: 研究者の意向を踏まえた検討案。提出済み申請の変更・承認は確認できていない。

## 1. 二つの比較が答える問い

2026年6月24日付の倫理審査申請書には、MEGAMOJIとEmojiLab.を同一参加者がそれぞれ使う比較が記載されている。これは既存ツールとの比較として成立する。一方、編集機能、初期値、UI、プレビュー等も同時に異なるため、その差だけから「スコア・改善コメントによる効果」を切り出すことはできない。

ユーザーが研究の主張として重視する、制作中のスコアと改善コメントの提示効果を検討するには、同一のEmojiLab.を用いた次の比較が有力候補である。

| 項目 | 支援なし | 支援あり |
| --- | --- | --- |
| 制作ツール | EmojiLab. | EmojiLab. |
| 入力、フォント、色、線、調整、出力、初期設定 | 同一 | 同一 |
| ライト・ダークや小サイズのプレビュー | 同一に揃える候補 | 同一に揃える候補 |
| 総合点・内訳・改善コメント | 非表示 | 表示 |

この比較で推定するのは、提示したスコア・内訳・改善コメントを**まとめて追加した効果**である。スコアとコメントそれぞれの単独効果までは分からない。支援あり条件にだけプレビューを追加する場合は、プレビューを含む支援パッケージ全体の効果となる。どの問いを優先するかを先に決める。

## 2. 評価の候補

- 参加者内で支援なし・ありを比較し、語句セットと順序を均衡化する。学習・持ち越し効果が残りうるため、順序も記録し、分析計画を定める。
- 制作時間、作業負担、自己評価だけでなく、別の評価者が制作条件を知らずに成果物を評価する。制作スコアの上昇を、人間の読み取り改善と同一視しない。
- 先行する実験1でスコアを調整する場合は、実験2開始前にバージョンを固定し、実験1と独立した制作課題・第三者評価で評価する。
- 既存ツールとの比較を維持する場合、実用上の比較という別の問いとして位置づける。2条件または3条件とするか、参加者負担・人数・持ち越しの影響を検討する。

## 3. 変更届に向けた確認

- 研究者は、比較対象について変更願の提出を検討している。これは意向であり、変更申請の提出や承認を意味しない。
- 承認済みの申請書と説明文を基準に、変更前・変更後・理由、機能差、制作課題、人数、時間、質問項目、第三者評価、外部通信・保存を確認する。
- 現行の[Study 2プロトコル](./study2-protocol.md)では、support条件に背景別・小サイズプレビューが書かれている。支援なし条件とプレビューを揃える場合、その記述は今後、教授との合意後に整合させる。
- 完了コード、同意・撤回、作成物の公表許諾についても、計画と参加者説明を整合させる。変更手続きの要否や必要書類は所属機関に確認する。
