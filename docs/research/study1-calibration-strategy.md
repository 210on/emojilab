# Study 1 スコア減点基準の検証・改訂案

作成日: 2026-10-28

状態: 研究者との議論を踏まえた検討案。刺激・分析・人数は未確定。倫理審査との照合、認知心理学・統計の専門家による確認と事前登録は未了。

## 1. 研究者の意図

現行のデザインスコアには、コントラスト、文字数、文字種、漢字画数、内側・外側線、ウェイト、横幅などに対する暫定的な基準がある。Study 1の目的は、各要素と人間の見やすさ評価の関係を調べ、現行の減点幅・閾値・助言を実測結果に照らして検討し、将来のスコア改訂につなげることである。

同時に、現行スコアが人間評価の順序や分布にどの程度対応するかも検証する。基準を作るための探索と、作った基準の独立検証は分ける。

## 2. まず「見やすさ」を定める

2026年6月24日付の申請書は、各刺激の「見やすさ」「意味の分かりやすさ」「解釈への自信」を7件法で尋ね、意味を自由記述する計画である。提案する主な測定対象は、申請書の**文字・形の判別しやすさの主観評価**。意味の理解や自信は別々の副次項目として扱う。

7件法は順序を持つが、1→2と6→7の心理的な距離が同じとは限らない。得られた平均をそのまま100点へ比例変換して「見やすさの損失に正確に一致する減点」と主張することはできない。[順序尺度と累積リンク混合モデルの研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC10439063/)を参考に、評価の分布を扱い、点数は用途に応じた支援指標として定義する。

文字列を正確に読めたか、素早く分かったか、色や表現意図を保てているかは、同じ測定値ではない。文字転記や反応時間を追加する場合、質問・提示方法が申請内容と異なるため、必要な確認・手続きを経た別のアウトカムとして扱う。現行の意味の自由記述だけから正確な文字転記率は導けない。

## 3. 操作できる要因と語句そのものの違い

| 要因 | 同じ語句で操作可能か | 比較・解釈 |
| --- | --- | --- |
| 塗り色 | 可能 | 色相を変えると明度・彩度・コントラストも変わりうる。意図した操作と実際の色対を記録 |
| 内側線・外側線 | 可能 | 有無・色・太さを変えると、色対だけでなく面積や輪郭も変わる。変更操作全体の効果とする |
| フォントウェイト | 可能 | 使用書体が実際に持つウェイトを固定して比較。線幅や字面も同時に変わる |
| 横幅・字間 | 可能 | 同じ語句で変更。描画後の実効変形率や文字間隔も記録 |
| 漢字の画数 | 通常は同一文字で変更できない | 別の文字・語句を比較するため、馴染み、使用頻度、意味、文字種、構造の差と交絡する。画数単独の因果効果とは断定しない |
| 文字数 | 内容を変えずに変更できない | 語句・意味・配置も変わる。自然な利用例の関連として扱い、文字あたり表示面積との関係を検討 |

日本語の小画面書体研究では画の密度や文字面積との関連が調べられ、背景条件により関係が変わることが報告されている。[日本語小画面フォントの可読性・判別性研究](https://www.jstage.jst.go.jp/article/jssdj/66/2/66_2_19/_article/-char/en)は実験の方向性を支えるが、その結果を絵文字用の減点値へ直接転用できない。

## 4. 色と内側線の相互作用: 具体例

「色が違っても線の影響が一定」と仮定せず、最初の重点比較として、塗り色2種類 × 黒内側線あり／なしの**2×2計4条件**を候補にする。例えばオレンジ系と青系を用い、各色は実際のコードを固定し、外側白線、幅、フォント、文字、背景、出力サイズを揃える。2色は色相だけでなく明度・彩度・色対コントラストも異なるため、これを「色相だけの効果」とは呼ばない。

| 条件 | 塗り | 黒内側線 | 白外側線 |
| --- | --- | --- | --- |
| A | オレンジ系 | なし | あり |
| B | オレンジ系 | あり | あり |
| C | 青系 | なし | あり |
| D | 青系 | あり | あり |

同じ語句を4条件それぞれで作り、参加者にはその語句を1回だけ提示する。語句ごとに別の参加者へA〜Dを均衡に割り当てれば、繰り返しによる学習を抑えながら、同じ語句のデザイン変更を比較できる。表示順、割当、使用フォント、背景、画像、描画版を固定・記録する。申請書どおり明暗背景を並べて一つの評価を取る場合、色×内側線の比較は**明暗を同時に見た条件**の効果であり、各背景の効果は分離できない。

事前に検討する比較は、オレンジ系での「あり−なし」、青系での「あり−なし」、その差である。最後の差は、線の効果が色条件により変わるかの相互作用を表す。いずれも主観評価に関する条件差であり、1つの比較だけで色・コントラスト・面積それぞれの原因を切り分けたことにはならない。

### 100人・一人15刺激の割当例

- **例:** 12語句×4条件＝48画像を用意し、一人には12語句を各1画像ずつ提示。残り3刺激は、事前に目的を決めた別の評価用刺激とする。
- 12語句の条件割当を4リストで循環させ、各リストでA〜Dをそれぞれ3回ずつ表示する。例えば語句番号 `0..11` とリスト番号 `0..3` に対し、条件番号を `(語句番号 + リスト番号) mod 4` とする。
- 完了100人を4リストへ25人ずつ均等に割り当てられた場合、各語句×条件には25人の評価、各条件の合計には300評価が入る。12刺激×100人＝1,200評価であり、**1,200人や独立した1,200語句ではない**。
- これは算術上の例であり、実際には途中離脱、割当の偏り、天井・床効果、参加者や語句のばらつきがある。検出力・信頼区間は未計算。対象人数、語句、重要な効果の大きさ、脱落率を置いた複数シナリオのシミュレーションが必要。
- 全体では48画像に加え別刺激を用意するため、申請書の「15点」が1人当たりだけでなく全体の刺激数に関わる可能性を含め、研究責任者・倫理審査窓口に事前に確認する。3刺激の役割、15点の所要時間と負担も確定するまで募集しない。

この例では横幅、画数、外側線の詳細な効果を同時に確定できない。それらを追加する場合、語句と条件、実験負担、比較数、必要人数が増える。2×2の交互作用の推定が難しいと分かれば、要因・水準をさらに絞る。

## 5. 人間評価から減点基準を作る

1. **基準版を固定**: 実験前のスコア規則、画像、語句、操作値、表示条件、スコアの算出版を保存する。
2. **人の結果を推定**: 条件ごとの7件法の回答分布、参加者間差、語句間差を確認する。累積リンク混合モデル等を候補にし、採用・仮定・収束・代替分析を事前に統計専門家と決める。
3. **具体的な差として報告**: 例えば「ある条件で『見やすい』側の回答が何ポイント多いか」という確率差や、回答分布の変化と信頼区間を示す。閾値「何以上を見やすいと扱うか」は事前に定め、別の閾値や順序モデルで頑健性を調べる。数字は実データ取得前に決めつけない。
4. **支援点数への写像を設計**: 比較結果に基づき、使用条件と基準となる構成を定めて、実用的な点数・助言へ変換する。どの損失を何点とするかには価値判断と運用上の選択が含まれる。非線形性、色×線、画数×ウェイトなどの相互作用を、データが支える範囲で検討する。
5. **不確実性を残す**: 語句数や参加者数が足りず差が不明確な要因は「効果なし」と断定せず、幅のある推定・未検証として扱う。特定の条件のみに適用可能な暫定規則を、全ての絵文字の普遍的な規則と扱わない。
6. **独立データで検証**: 同じ回答で減点幅を選び、同じ回答で改訂版の精度を報告すると過大評価しうる。実験前に固定した現行版の評価と、実験後の改訂版の探索的構築を明確に区別する。新しい参加者・語句のデータで再評価するか、参加者・語句単位の分割・交差検証を目的に合わせて事前に設計する。どちらを新しくしたかを明記する。

この過程を経ても「1点がすべての人にとって同じ見やすさの損失」を保証するものではない。想定する対象・表示環境・語句の範囲で、人の評価をよりよく説明・予測するための点数として検証する。

## 6. 認知心理学上の確認

- 語句への馴染み、意味の推測、読者の知識、文字種は視覚情報以外にも影響する。語句を適切に選び、語句差を分析に含める。[日本語の視覚的馴染みと語頻度に関する研究](https://www.sciencedirect.com/science/article/pii/S0093934X1200020X)
- 同じ語句を同じ参加者が繰り返し見ると、記憶や慣れが生じる可能性がある。各語句1回の割当、練習との分離、条件を混ぜた順序で影響を抑える。
- 参加者と語句の繰り返しを独立観測として数えず、双方のばらつきを考慮する。[Baayenらの混合効果モデル](https://quantling.org/~hbaayen/publications/baayenDavidsonBates.pdf)
- 小サイズ画像が読めるかどうかでの参加者選抜は、読みづらさを感じる人を排除する可能性がある。申請書の表示確認と、研究上の選抜基準との整合を検討する。
- 端末・表示・視距離、回答形式、主観評価への先入観、刺激選択、課題順、欠測は残る。スコアや条件名を伏せ、分析と除外基準を事前に定め、限界として報告する。

## 7. 指導教員と優先して決めること

1. 主アウトカムを申請書どおりの7件法の見やすさにするか、文字転記を追加するか。
2. 本実験で最初に重点比較する要因と水準。色×内側線の4条件を優先するか。
3. 15刺激という記載と複数リスト・48画像の関係、人数・募集方法・設問変更の倫理上の手続き。
4. 語句の選定方針、必要な語句数、条件割付、妥当な効果の大きさと検出力・精度。
5. 現行スコアの検証、新基準の探索、独立した検証をどの段階で行うか。
6. 明暗並列の単一評価で十分か、背景別の評価が必要か。
