# Study 1 配置・横幅の連続調査案

作成日: 2026-10-28

状態: 研究者用の準備・検討。参加者の募集・データ収集は未実施。刺激・質問・人数・実施回数は未確定で、承認書類と変更手続きの確認が必要。

## 1. 問い

3文字を正方形の絵文字に配置するとき、1行と2+1行では、文字の大きさ、字形の横幅、字間、行間、余白、輪郭の割合が変わる。どちらが見やすいかは実測前には決められず、面積ロスだけで判断できない。1行を横幅33%にしなければならないわけでもなく、実際のフォント、配置と出力サイズに依存する。

スコアの目的は、これらの違いに対する人の評価と、将来的には読み取り結果に基づいて減点・助言を検討することである。見やすさの主観評価、意味の理解、文字を正確に読めたか、制作時の好みは別のアウトカムである。

## 2. 調査を分ける

| 調査案 | 優先する問い | 主な比較 | 備考 |
| --- | --- | --- | --- |
| 配置 | 1行と2+1行のどちらが評価されるか | 同じ3文字・フォント・色・線を用いた、出力枠を統一した実用的な2配置 | 大きさ、余白、文字幅、行数が同時に変わるため、配置パッケージ全体の差として扱う |
| 横幅変形 | 横幅変更は評価にどう関係するか | 同じ語句・1行・同じ基準文字高で横幅のみ変更 | 画面上での実効横幅、文字高、文字間、線幅も測り、他の変化を記録 |
| 色と内側線 | 線の効果が塗り色や背景条件によって変わるか | [色×内側線の4条件案](./study1-calibration-strategy.md) | 明暗並列の単一評価では背景別の効果を分離できない |
| 高画数 | 高画数を含む語句の評価と文字構成の関係 | 複数語句、画数・文字種・馴染み等を記録 | 文字自体は同じまま画数を変えられず、画数単独の因果効果と断定しない |

順序と回数は仮案であり、各回に独立した研究課題・分析計画・参加者募集条件を定める。複数回100人ずつ募集しても、語句数や条件の交絡を放置すれば個々の効果は分からない。同一参加者の再参加、刺激への慣れ、データの重複は、事前に許可・排除の方針を決める。

## 3. 配置調査の割当例

- 15語句について、同じ文字列で1行と2+1行を作る。各参加者は各語句を1回だけ、計15刺激を見る。
- 2つのリストで語句ごとの配置を反転する。各リストに両配置が入るようにし、100人が50人ずつ完了すれば、各語句×配置に約50評価が入る。
- 提示順は条件の偏りを抑えてランダム化する。参加者に条件名やスコアは見せない。参加者・語句の反復を考慮した分析を事前に決める。
- 15語句×2画像＝30画像となる。倫理申請の「15刺激」と複数リストの関係を確認する。100人で十分な精度が得られるかは、語句数・評価のばらつき・欠測を含めたシミュレーションで検討する。
- 表示は申請書どおり固定のライト・ダーク背景に32 CSS pxで並べ、一組への評価とする案。この場合、背景ごとの効果を分離できない。

## 4. 横幅調査の設計上の注意

同じ1行・同じ語句で、横幅100%と70%など、2水準を比較する案。70%は**試作用の例**であり、研究上の許容値として確立された値ではない。さらに中間水準や2+1行での反応を知るには別の条件・画像数が必要。

既存のEmojiLab.出力は透明領域を切り詰めて正方形へ正規化するため、同じ32 CSS pxの枠でも、設定した横幅倍率が最終画像内の文字高さや実効横幅と一対一にはならない。線幅、字間、配置や正規化も変わりうる。**設定値だけでなく最終画像の実測を優先**し、少なくとも画像の版・幅高さ、文字領域、配置、線幅、周囲の透明部分を記録する。字形個別の実効縦横比を論じるなら、個々の文字境界と基準文字を別途測る。研究者用プレビューでは設定値と出力を並べて確認できるが、物理的な字形寸法の自動測定はまだ実装していない。

横幅の因果的影響をできる限り分けたい場合は、文字高さ・配置位置・最終枠・字間・線幅を固定して、横幅だけを変えた刺激生成方法を別途設計し、実画像で検証する。枠に収めるために高さや字間も変わる場合、複合操作として報告する。

## 5. 研究者用の準備画面

ローカル作業ツリーの試作画面 `/research/layout-lab` は3文字の入力に対して、1行100%、1行70%、2+1行100%の候補を既存EmojiLab.描画で生成し、32 CSS pxで明暗背景に並べ、拡大画像と比較する。入力と設定のJSONは手動でダウンロードできる。参加者の回答は取得しない。試作画面のコードは研究文書とは別に管理され、公開サイトへの反映は未確認。

- フォントを含む描画環境、ブラウザ、画像のハッシュ、刺激ファイル、色、線、背景を固定しない限り、研究用刺激として確定しない。
- JSONは設定の記録であり、画像自体、フォントファイル、レンダリング環境や実測値の固定・検証を保証しない。
- 研究者用画面と、同意・撤回・回答回収・完了コード・募集を含む本番実験画面は別である。本番の回収・認証・削除機能は未実装。
- `scripts/auditLayoutPreparation.ts` は試作用の条件生成と割当の均衡性を確認する。実際の参加者割当、途中離脱後の補充や不正対策を実装するものではない。

## 6. 研究・実施上の要確認事項

1. 実際の倫理審査の承認版と変更届を確認し、複数回の募集、延べ人数、刺激、項目、ポイント、端末、回収・撤回を照合する。
2. 同意説明・参加条件・回答拒否・14日間の撤回・安全な回答保存・完了コードを、承認された運用に合わせて実装・テストする。
3. 既存のStudy 1画面は表示サイズの記録と実際が一致せず、回答をサーバーへ回収しないため、そのまま本番に使用しない。
4. 主な尺度、語句の選定、主な比較、除外・欠測・順序、参加者と語句の変動、必要な精度・分析方法を教授と確定する。
5. 基準の調整に用いるデータと、その基準を評価するデータを分ける。別の回で得た結果を統合する際は、募集、条件、版、参加者の重複を記録する。
