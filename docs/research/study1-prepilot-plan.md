# 実験1 予備調査の実施前検討案

作成日: 2026-10-28

状態: 指導教員との確認用。未承認の提案を含む。募集・実参加者の回答収集・正式な事前登録は行っていない。以下の要因選択は第一候補であり、研究者による最終決定ではない。

## 1. 今回進める範囲

これまでの複数案から、最初の検討対象を「色と黒内側線の組合せ」に絞る。目的は、色によって内側線の追加が異なる評価を受ける可能性を調べるための準備である。全デザイン要因の減点幅を一度に決める調査にはしない。

次の三段階を区別する。

| 段階 | 今回の準備 | 判断すること | 判断しないこと |
| --- | --- | --- | --- |
| 研究者による内部確認 | 仮画像・4リスト・全画面を確認 | 誤字、表示、割付、説明の不足 | 人間評価への効果、必要人数 |
| 予備調査 | 承認範囲確認後、16人程度を運用上の候補にする | 説明の理解、負担、欠測、尺度の使われ方、刺激の極端な難易度 | 相互作用の確証、普遍的な減点値 |
| 要因比較の本調査 | 予備結果・推定精度の検討後に別途固定 | 事前に定めた要因比較と不確実性 | 同じデータで改訂したスコアの独立検証 |

16人は4リストに4人ずつ割り付けるための**運用上の案**で、検出力に基づく人数ではない。予備調査も人を対象とする研究として、必要な倫理手続き・同意・保存方法を確認する。本調査100人案も十分性は未検証である。[3]

## 2. 研究課題と測定対象

研究課題は「明暗背景を並べた32 CSS px表示で、黒内側線の追加による判別しやすさの評価差が、指定した橙と青の間で異なるか」である。

主な評価項目は、申請書の見やすさに対応する「文字や形の判別しやすさ」の7件法とする。意味の分かりやすさ、解釈への自信は別の副次項目とし、三項目の平均を総合視認性の正解値にはしない。意味の自由記述は任意とし、文字転記の正答率へ読み替えない。所要時間は入力や尺度回答を含み、認知反応時間とは呼ばない。

予想は、明るい橙では黒線が境界の判別を助ける一方、青では追加輪郭の必要性が異なる可能性がある、というもの。ただし、青でも線の効果がある、橙でも悪化する、差が不明確という結果を許容する。予想どおりになる刺激だけを結果確認後に採用しない。比較は両方向の差を扱う。

## 3. 操作する四条件

| ID | 塗り | 黒内側線 | 白外側線 |
| --- | --- | --- | --- |
| A | 橙 `#FF9914` | なし | あり・設定幅10 |
| B | 橙 `#FF9914` | あり・設定幅4 | あり・設定幅10 |
| C | 青 `#386CB0` | なし | あり・設定幅10 |
| D | 青 `#386CB0` | あり・設定幅4 | あり・設定幅10 |

色は現行PCCSブライト系の候補から選んだ**比較用の二つの色指定**である。明度・彩度・コントラストも変わるため「色相だけの効果」や、全ての黄色・青色への一般的な結論とは呼ばない。幅4・10は現在の描画で確認する操作値であり、32px表示で4px・10pxの線になることを意味しない。また、この線幅が学術的に最適と証明された値ではない。

固定候補はLINE Seed JP・700、横幅100、字間0、幅揃えOFF、全語句1行。背景は白 `#FFFFFF` と濃灰 `#1D1C1D`、同じ32×32 CSS px画像を左右に並べる。この指定が妥当な難易度を作るかは内部確認と予備調査で確認する。背景別の評価は取らず、結果は二背景を同時に見た場合の評価に限定する。16px表示やスマートフォンへの一般化は別調査を要する。

線を追加すると、最終画像の外接範囲・正規化後の文字サイズ・塗り面積なども変化しうる。今回は**現在の生成方法で内側線を追加する操作全体**を比較する。純粋な色差だけ、線幅だけの効果を分離したとは主張しない。最終画像は開始前に固定し、輪郭・塗り・余白・欠け・アンチエイリアスを拡大と32pxの両方で確認する。試作は動的描画であり、画像固定はまだ済んでいない。

## 4. 語句と割付

申請書の15候補語句を暫定的に用い、各語句を4条件で作る。全体では60画像、各参加者が見るのは各語句1回の15画像である。申請書の「15点」とこの複数版の関係は、人数・募集・謝礼と併せて確認する。

| 語句 | リスト1 | リスト2 | リスト3 | リスト4 |
| --- | --- | --- | --- | --- |
| 了解 | A | B | C | D |
| 承知 | B | C | D | A |
| 感謝 | C | D | A | B |
| 御礼 | D | A | B | C |
| 確認中 | A | B | C | D |
| 対応中 | B | C | D | A |
| 確認済 | C | D | A | B |
| 対応済 | D | A | B | C |
| 共有済 | A | B | C | D |
| 返信済 | B | C | D | A |
| 完了 | C | D | A | B |
| 保留 | D | A | B | C |
| お願い | A | B | C | D |
| 助かる | B | C | D | A |
| 最高 | C | D | A | B |

一人にはA〜Dがそれぞれ3または4回入る。15は4で割り切れないため、各人内で完全に同数にはならないが、4リスト全体では各語句が全条件に一度ずつ対応する。順序は割付後に参加者別のseedでシャッフルし、実際の順序を記録する。同じ語句を複数回見せず、スコア・条件名・期待する改善方向を伏せる。ただし見た目の違い自体は隠せない。

| 人数の例 | 一人の提示数 | 各リストの人数 | 全評価数の最大 | 各条件の評価数 | 各語句×条件の評価数 |
| --- | --- | --- | --- | --- | --- |
| 16人 | 15 | 4 | 240 | 60 | 4 |
| 100人 | 15 | 25 | 1,500 | 375 | 25 |

これは欠測・離脱のない均衡割付の算術値であり、独立した240人・1,500人のデータにはならない。[2] 同時アクセス、離脱、再参加を含む実際のサーバー割付は未実装。リストは同時期にランダムな順で均衡配分し、時期や曜日をリストと結び付けない。離脱者を事後に消して完成者だけを都合よく補充せず、割付時点と完了時点の件数を両方残す。追加募集・再参加・停止規則を募集前に固定する。

候補語句は日常的な2〜3文字に偏る。一般語を推測できること、文字数・文字種・馴染みの差が残る。これは高画数文字や4文字以上の語句の減点を校正する刺激セットではない。語句を結果の都合に応じて選び直さない。

## 5. 予備調査で集計するもの

- 全体とリスト別の開始・途中終了・完了の件数、質問ごとの欠測数と理由が分かる範囲
- 15試行を含む実際の所要時間、理解・操作・表示上の問題。聞き取りや追加質問を人から収集する場合も、収集項目として事前に確認する
- 条件・語句ごとの1〜7の回答分布、端点1と7への集中。1語句×条件4評価だけで難易度や効果を確定しない
- 記述回答が求める意味の回答になっているか。ただし記述量・誤答・低評価だけで謝礼や参加資格を否定しない

予備調査に普遍的な合否基準は置かない。少なくとも、刺激の誤表示、回答と刺激の対応間違い、説明と実際の撤回・謝礼処理の不一致、回収失敗があれば募集を進めず修正する。回答の天井・床への集中は分布を示して教授と検討し、都合のよい条件差が出たことを次段階への合格条件にしない。調整した後は新しい刺激版・手順版を付け、旧版の回答と無条件に合算しない。

## 6. 要因比較の分析候補

本調査の主要比較は色×内側線の相互作用とする案。橙内のB対A、青内のD対Cを副次比較とする。単に「B対Aは有意、D対Cは非有意」だから差があるとは結論しない。相互作用を直接推定する。7件法は順序尺度として扱い、参加者と語句の繰り返しを考慮する累積リンク混合モデルを候補とする。[1][2]

例として、色 `C` と線 `S` をそれぞれ `-0.5 / +0.5` で符号化し、参加者 `p`・語句 `w` の回答 `Y` を次の形で考える。

```text
logit P(Y[p,w] <= k) = threshold[k] - eta[p,w]   (k = 1..6)
eta = betaC*C + betaS*S + betaCS*C*S + betaOrder*中心化試行順
      + 参加者効果 + 語句効果
```

参加者・語句別のランダム傾き、比例オッズ仮定、推定法、収束不良への対処は、シミュレーションと統計指導のもとで実施前に定める。上の式だけで分析計画が完成したことにはしない。相互作用の方向や有無は採用するモデルの尺度にも依存する。モデル上の係数と、回答確率の差を区別して報告する。

各条件の予測回答分布と不確実性を示す。補助的に `P(Y >= 5)` を示す場合、5は説明用の事前に固定する区切りであって、実証された「合格ライン」ではない。副次比較を検定するなら、比較族と多重性の扱いも開始前に固定する。予備調査では記述的集計を中心とし、有意差の有無で規則を採否しない。

主な欠測は、未回答・途中終了・表示失敗を区別し、低い見やすさ得点に置き換えない。全項目同じ回答、短い所要時間、読めなかったことだけで機械的に除外しない。除外規則・対象集団・解析対象、条件別欠測と離脱、感度分析を募集前に定める。除外判断は条件差の検定結果を見ずに行う。

## 7. スコアに反映できる範囲

この比較で得られるのは、指定色・線幅・語句群・生成方法・表示条件における主観評価の差である。画数、横幅、配置、外側線幅などの個別減点は今回のデータから決めない。色と線が独立に一定点だけ効くという加算仮定も検討対象であり、相互作用があれば条件付きの助言が必要になりうる。

7件法の差をそのまま100点の減点に比例換算しない。現行スコアの版を固定して評価との対応を見る分析と、データから新しい重みを探索する分析を分ける。改訂版の性能は、別参加者・別語句への適用を検証できる別データで確認する。今回の60画像だけで検証できる範囲を超えたスコアの正当化には使わない。

## 8. 教授へ確認する事項と着手条件

1. 第一候補を色×内側線とするか。配置・横幅を先にするなら別の計画に変更する
2. 主観的判別しやすさを主項目とし、意味と自信を分ける方針と、実際の質問文・尺度の承認範囲
3. 予備16人案・本調査100人案・60画像・募集とポイント・保存先について必要な変更手続き
4. 参加者・語句のばらつき、意味のある最小差、想定欠測を変えた精度検討と、本調査の必要人数
5. [同意説明の草案](./study1-consent-draft.md)の未確定箇所、14日間の撤回と分析・公表時期、保存運用

これらと画像固定・回収テストが済むまで募集しない。現在のローカル試作は4リストの内容を確認できるが、正式な同意取得、参加者割付、回答保存・送信、完了コード、撤回を実装した本番実験ではない。

## 10. 準備段階の点検結果

2026-10-28、ローカル試作について次を確認した。人間の見やすさを検証した結果ではない。

- 4リストそれぞれ15語句、語句の重複なし、各語句に全4条件が一度ずつ対応することを自動確認した
- 一人あたり各条件3または4試行になること、均衡した16人・100人の計算例で上表の件数になることを自動確認した
- 同じ語句の条件間で変更する設定が塗り色と黒内側線の有無だけであることを自動確認した。最終ピクセル上で他の見た目が一定になることを保証するテストではない
- リスト4を選び、説明・表示確認・参加条件・15問・完了までブラウザで遷移した。型チェック、ビルド、設定・割付の検査が通った
- 最終刺激画像、実参加者の同意・回答保存、完了コード、撤回、推定精度シミュレーション、分析モデルの検証は未完了
