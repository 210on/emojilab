# 実験1 参加説明と同意確認の草案

作成日: 2026-10-28

**研究者・指導教員の確認用。参加者にそのまま提示しない。** 未確定箇所があり、承認済みの説明書ではない。実装された手続きが本文と一致することを確認してから使用する。連絡先や承認通知などの原資料を公開リポジトリへ転載しない。

## 1. 研究の名称と目的

研究名称: チャットプラットフォームにおける日本語カスタム絵文字の視認性評価および作成支援ツールの有用性検証

この調査では、日本語の文字を含む小さな絵文字について、文字や形の見分けやすさと、意味の分かりやすさを調べます。結果は、絵文字を作る人に見やすさの目安や改善案を伝える仕組みの検討に使います。あなたの能力を試すものではありません。文字が分からない場合も、そのままの評価をお願いします。

## 2. 参加できる方

18歳以上で、日本語の説明と質問を理解でき、普段の視力または眼鏡・コンタクトレンズ等の矯正視力でPC画面の文字を読める方。チャットツールの利用経験があり、デスクトップPCまたはノートPCから参加できる方を対象とします。スマートフォン・タブレットは対象外です。

## 3. 調査の内容と時間

ブラウザの表示倍率を100%にして、表示方法を確認してください。15点の絵文字を順に表示します。各画像は32×32 CSSピクセルで、明るい背景と暗い背景に並べて表示します。両方を見て、文字や形の判別しやすさ、意味の分かりやすさ、解釈への自信を、それぞれ1〜7で回答してください。意味を尋ねる自由記述もあります。

所要時間は10〜15分を予定しています。【要確認: 予備テストで同意・確認・終了手続きを含め実測し、必要なら変更する】

## 4. 参加は任意です

参加しなくても、途中でやめても、回答しない項目があっても、成績・指導・所属等の扱いで不利益はありません。回答したくない項目は飛ばせます。目の疲れ、不快感や負担を感じたら、いつでも休憩・中止してください。

【要確認: ポイントの付与条件と、途中終了・回答拒否・参加資格を満たさない場合の扱いを、募集文と同じ内容で記載する。ポイントが必ず支給される、または途中終了で必ず不支給となる等の未確認の約束をしない】

## 5. 記録するものと記録しないもの

絵文字に対する評価、意味の自由記述、回答に要した時間を記録します。年齢層、チャット・カスタム絵文字の利用や作成経験、デザイン経験等について質問する予定です。【要確認: 実際に採用する属性項目だけを列挙する】

研究用の回答として氏名・住所・電話番号・音声・映像・画面録画・スクリーンショットは収集しません。自由記述には、あなたや他の方の名前、連絡先、勤務先、秘密の情報などを書かないでください。撤回の連絡で受け取るメールアドレス等は回答データと分離し、その目的に限って扱う運用を確認します。

【要確認: 表示確認の結果、ブラウザや表示範囲等の補助情報を記録するか。収集する場合は目的と内容をここに追記する。試作には回答のサーバー保存や時間計測は未実装】

## 6. オンラインでの回答と保存

オンライン調査では、研究者の調査サイトと、回答保存に用いる外部サービスに通信します。サイトや外部サービスの運営事業者には、接続元IPアドレス、アクセス日時等の通信記録が残る場合があります。東京リージョンを選んだことだけで、全てのログ・バックアップ・サポートに伴う処理が日本国内に限定されるとは保証できません。

【要確認: Supabaseを含む実際の保存先、アクセスできる管理者、オンライン一時保管期間、研究室PCへの移行・削除、バックアップ・通信ログ、大学の管理規程との適合を確認して説明する。公開鍵とアクセス制御もテストする。未確認の保存先に同意した扱いにしない】

研究結果は修士論文、学会発表等に使用する予定です。個人を特定できる形で結果を公表しません。研究データは成果公表後10年間保存する計画です。【要確認: 現行の承認版との一致、起算点、保存場所、期間満了時の廃棄方法】回答の原データを公開GitHubリポジトリへ置くことはしません。

## 7. 終了後の撤回

参加時に撤回用IDを表示する予定です。このIDを保存してください。参加後14日以内に、撤回用IDを添えて研究実施者に連絡すると、対応する研究データを削除する計画です。撤回用IDはポイント確認用の完了コードとは別のものとして案内します。

【要確認: 途中終了者もIDを保存できる方法、14日の起算・締切、受付連絡先、処理と通知、対応表・複製・バックアップ・ログの扱い、ポイントとの関係を運用として確定する】

撤回期限後の対応情報の廃棄と、その後にデータを個別に特定して削除できなくなる時点を、実際の手順に合わせて説明します。IDだけを消したことをもって不可逆的な匿名化が保証されるとは扱いません。撤回可能期間中の公表・対応情報破棄によって撤回を妨げない手順を確認します。

## 9. 同意確認欄の案

各欄は初期状態を未選択とします。同意しない場合は、研究用の回答を送信せず終了できるようにします。研究用ID発行や保存のタイミング、アクセスログとの区別も検証します。

- [ ] 目的・手順・所要時間・記録する内容について読み、理解しました
- [ ] 参加は任意で、回答しないことや途中でやめることができると理解しました
- [ ] データの保存先・保管方法・期間、外部サービスの利用について理解しました
- [ ] 撤回用IDの保存、撤回できる期間と方法、その後の削除の制約を理解しました
- [ ] 確定したポイントの条件と問い合わせ先を確認しました
- [ ] 上記の説明に基づいて、この調査への参加に同意します

実験1では参加者自身が画像を制作しないため、実験2の「作成物を公表する任意同意」をそのまま流用しません。参加者の自由記述を原文で公表する場合は、説明・同意・識別リスクを別途確認します。
